rbusObject_SetValue[Type]

These functions set the value of a property by name on an object, where the value is internally initialized with the corresponding type and data.

If a property with the same name does not exist, a new property is created. Ownership of any previous property/value will be released.

Parameters
objectAn object.
namethe name of the property inside the object to set the value to
valuethe type specific data to set on the object's property
