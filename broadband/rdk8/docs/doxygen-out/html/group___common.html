◆ rbusLogHandler

typedef void(*) rbusLogHandler(rbusLogLevel_t level, const char *file, int line, int threadId, char *message)

A callback handler to get the log messages to application context.

A component that wants to handle the logs in its own way must register a callback handler to get the log messages.

Parameters
levelthe log level
filethe file name that it prints
linethe line number in the file.
threadIdthe threadId.
messagesthe log message the library prints.
Returns
None.
