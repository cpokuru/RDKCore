Component use this API to open direct connection to the provider. 

Rbus supports a mode that optimizes performance for very frequent, high data rate transfers or rbus operations that need extremely low latency. This is known as rbus\+\_\+direct mode. While this mode improves performance, reduces CPU usage and improves latency, it also uses more memory and resources compared with normal rbus operation. Rbus\+\_\+direct mode should only be used where it\textquotesingle{}s needed and avoided where its not needed. Developers should use normal rbus operation modes unless there are special circumstances that require rbus\+\_\+direct mode. Developers should NOT use rbus\+\_\+direct mode for all operations. For more information on rbus\+\_\+direct see the instructions for \doxylink{group___consumers_ga413ba5cd92734c0454d72a2477b99182}{rbus\+\_\+open\+Direct()} in \doxylink{rbus_8h}{rbus.\+h}.
