For each \doxylink{group___events_gaa057c1d714c08fa0c831a0bb88e08ac9}{rbus\+Event\+Subscription\+\_\+t} subscription, the event\+Name and handler are required to be set. Other options may be set to NULL or 0 if not needed. Subscribing to all items in the subscription array is transactional. ~\newline
 That is, all must succeed to subscribe or none will be subscribed. The subscribe\+Handler is called after either all subscriptions were successfully made to providers, any one subscriptions received an error response from a provider, an unrecoverable error occurs, or retry timeout reached. If timeout is positive, internal retries will be attempted for each subscription that cannot be routed to an existing provider, and the retries will continue until either a provider is found, an unrecoverable error occurs, or retry timeout reached.
