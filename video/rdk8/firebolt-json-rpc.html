JSON-RPC 2.0 Compliance

The URL used by the Firebolt Client Library to connect to the Firebolt API Gateway includes the RPCv2=true query parameter, confirming that the Client Library uses and accepts only compliant JSON-RPC as specified in this document.

All names used for matching, including method and parameter names, are case sensitive as stated in Section 2 of the JSON-RPC 2.0 Specification.

Method Calls

MessageExampleNotes
Method call with no parameters
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Module.method"
}
Params is not provided
Method call with one or more parameters
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "Module.method",
  "params": {
    "attr1": 1,
    "attr2": "value2"
  }
}
Params is an object. Arrays are not used
Error response
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -40300,
    "message": "Method not permitted"
  }
}
Success with no return value
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": null
}
Success returning a single primitive value
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": 42
}
result is a primitive type
Success returning a single attribute that is an array of values of the same primitive type
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": [
    "spa",
    "eng"
  ]
}
Success returning more than one value
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "attr1": 1,
    "attr2": "value2"
  }
}

Notifications

MessageExampleNotes
Subscribe for notification
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "Module. onSomething",
  "params": {
    "listen": true
  }
}
Unsubscribe from notification
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "Module. onSomething",
  "params": {
    "listen": false
  }
}
Subscription request failed
{
  "jsonrpc": "2.0",
  "id": 2,
  "error": {
    "code": -12345,
    "message": "Subscription request failed"
  }
}
Subscription request succeeded
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": null
}
Notification of a primitive type
{
  "jsonrpc": "2.0",
  "method": "Module. onSomething",
  "params": {
    "value": 42
  }
}
The params object has a single member that is always called "value"
Notification of a single attribute that is an array of values of the same primitive type
{
  "jsonrpc": "2.0",
  "method": "Module. onSomething",
  "params": [
    "spa",
    "eng"
  ]
}
Params is an array that represents one attribute, not positional parameters in this case C++ example: void onSomething( std::vector<std::string> bar )
Notification of an object
{
  "jsonrpc": "2.0",
  "method": "Module. onSomething",
  "params": {
    "attr1": 1,
    "attr2": "value2"
  }
}
params contains all the attributes of the object
Notification of a list of objects
{
  "jsonrpc": "2.0",
  "method": "Module. onSomething",
  "params": [
    {
      "attr1": 1,
      "attr2": "value2"
    },
    {
      "attr1": 2,
      "attr2": "value4"
    }
  ]
}
Params is an array that represents one attribute, not positional parameters in this case. Rarely used
